World Wide Web (www)

La malla mundial

En informática, la World Wide Web o malla mundial es un sistema de distribución de documentos de hipertexto interconectados y accesibles vía Internet. Con un navegador web , un usuario visualiza sitios web compuestos de páginas web que pueden contener textos, imágenes, vídeos o animaciones u otros contenidos multimedia, y navega a través de esas páginas usando hiperenlaces.


La Web se desarrolló entre marzo de 1989 y diciembre de 1990 por el inglés Tim Berners-Lee con la ayuda del belga Robert Cailliau1 mientras trabajaban en el CERN en Ginebra, Suiza, y publicado en 1992.
