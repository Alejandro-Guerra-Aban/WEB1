## 📌 Acerca del proyecto

**WEB1** es un repositorio académico destinado a recopilar, organizar, documentar y conservar los materiales desarrollados durante el Ciclo Formativo de Grado Superior en **Desarrollo de Aplicaciones Web (DAW)**.

El proyecto centraliza los recursos correspondientes a diferentes módulos profesionales, incluyendo documentación teórica, unidades de trabajo, ejercicios, actividades, prácticas, proyectos y herramientas complementarias.

Su finalidad es disponer de un espacio organizado donde almacenar y consultar el material académico, facilitar el seguimiento de las asignaturas y mantener un historial de las modificaciones realizadas mediante Git y GitHub.

<div align="center">

| 📚 Material | 💻 Prácticas | 📝 Documentación | 🌐 Recursos |
|:---:|:---:|:---:|:---:|
| Apuntes y teoría | Ejercicios y proyectos | Guías y actividades | Herramientas y referencias |

</div>

### 🎯 Objetivos del repositorio

- Centralizar los materiales académicos de los diferentes módulos de DAW.
- Organizar los contenidos por asignaturas y unidades de trabajo.
- Conservar las prácticas y ejercicios realizados durante el curso.
- Mantener documentación en diferentes formatos.
- Facilitar la consulta y recuperación de materiales.
- Utilizar Git y GitHub para gestionar las versiones y actualizaciones.
- Ampliar progresivamente el repositorio conforme avance el ciclo formativo.

### 🏷️ Convenciones de commits

Se utiliza una nomenclatura basada en Conventional Commits para identificar el propósito de cada modificación.

| Prefijo | Descripción | Ejemplo |
|:---|:---|:---|
| ✨ `feat:` | Incorporación de contenido nuevo. | `feat: añadir prácticas HTML` |
| 📝 `docs:` | Actualización de documentación. | `docs: actualizar README` |
| 🐛 `fix:` | Corrección de errores. | `fix: corregir ejercicio HTML` |
| ♻️ `refactor:` | Reorganización de archivos o código. | `refactor: reorganizar prácticas` |
| 🔧 `chore:` | Tareas de mantenimiento. | `chore: ordenar directorios` |
| 🎨 `style:` | Cambios de formato o presentación. | `style: mejorar estilos CSS` |
| 🧪 `test:` | Incorporación o modificación de pruebas. | `test: añadir pruebas` |

**Ejemplos de commits del repositorio:**

```bash
feat: añadir prácticas de HTML de la UT1
docs: incorporar apuntes de sistemas informáticos
feat: añadir ejercicios del modelo entidad-relación
docs: añadir documentación de AWS Academy
fix: corregir enlaces internos del README
chore: reorganizar directorios de prácticas
```
